# Clipforge

Independent SaaS for turning customer-uploaded English podcasts and talking-head interviews into editable 9:16 shorts. BrainrotAI was inspected read-only for rendering ideas; the two products are not coupled and no BrainrotAI code is imported.

## Real product path

1. Better Auth creates an account with **real verification mail** (Cloudflare Email Sending when a sender domain is onboarded; Resend is a fallback). Alchemy's **built-in Stripe provider** provisions a TEST-mode product, monthly price, restricted Checkout/Portal bindings and verified webhooks. Only a paid subscription invoice grants source minutes. A source reserves `ceil(duration / 60s)` minutes; terminal ingestion failures release them.
2. Customer uploads a browser-decodable MP4 or WebM (up to 5 GiB and 2 hours), in resumable 32 MiB Worker-proxied R2 multipart parts. MOV/ProRes is rejected before upload: convert it to H.264/AAC MP4 for a reliable editing preview. The private Container probes the source and extracts 60-second, ~0.5 MiB mono audio segments. Worker streams and validates the segment manifest, storing each segment privately in R2.
3. By default, Cloudflare Workers AI's **`@cf/deepgram/nova-3`** transcribes each segment through the native binding, with word-level timing and chunk-local diarization. An explicit, separately keyed `deepgram` backend remains available for guarded staging fallback; it transcribes the same short chunks and is never activated automatically after a Cloudflare failure. Workflows checkpoint each segment result to R2, normalize timestamps, store one D1 row per timed word, suggest clips using transcript pause/context windows and optionally rank suggestions with **`@cf/meta/llama-3.3-70b-instruct-fp8-fast`**. Inference is real when deployed; no inference has been invoked by local tests. A per-chunk progress indicator updates in the editor.
4. Customers review suggestions, adjust boundaries, manual focal-point crop, title and word captions/timing, and insert missing or delete hallucinated captions. Simultaneous words render on separate, non-overlapping ASS event lines. Cut extensions append newly exposed transcript words without erasing caption corrections. The display-oriented FFmpeg crop geometry is shared with the browser preview. The same FFmpeg Container produces H.264/AAC vertical MP4 with burned-in captions, stored privately and served by authenticated ranged playback/download. Face tracking and speaker-to-face association are deliberately not advertised.

TanStack Start/React + Better Auth on Workers; D1 for auth, projects, transcript, jobs and period-scoped credit ledger; R2 for private media; Workflows for durable background steps; a D1-leased two-slot global scheduler and Bun/FFmpeg in Cloudflare Containers; Alchemy v2 for resource definitions and built-in Stripe. The provisional plan is **$29/month for 120 source minutes** and up to 20 exports/source. Media expires after 90 days; expired projects hide playback/download and can be deleted, and authenticated project deletion purges source, chunks, transcript checkpoints, word rows and all export revisions (but retains pseudonymous billing/inference usage records). An hourly bounded Cron sweep and owner-visit reconciliation purge eligible terminal projects older than 91 days, including dormant accounts. Queued processing/export can be retried from the editor and queued uploads cancelled in the library; hourly queue recovery retries lost starts by deterministic Workflow ID and releases jobs still queued after 24 hours. Running exports with a confirmed terminal Workflow status are reconciled for retry or project deletion; missing/unknown Workflow states remain fenced and require operator investigation. Provider costs and commercial terms need confirmation before public paid release.

## Verification status

Worktrees can share local-only configuration without copying secrets or private artifacts; see [local worktree environment setup](docs/worktree-env.md). Staging/deploy credentials are never loaded by the local `.envrc`.

For every candidate commit, run `bun scripts/verify.ts local` and inspect its SHA-pinned, ignored `.local-dev/verification/` report. The reproducible checklist and coverage gaps are in [the verification skill](.agents/skills/clipforge-verify/SKILL.md) and [feature map](.agents/skills/clipforge-verify/references/feature-map.md). The read-only `bun scripts/inspect.ts` snapshot (or Pi `/inspect` in this project) shows worktrees, PR CI, exact-SHA local evidence, and Herdr agent states; it does not mark untested staging paths ready. See `AGENTS.md` for autonomous PR boundaries.

`bun run typecheck`, `bun test test renderer`, `bun run build`, `bun run test:e2e`. The browser test exercises auth, upload, caption insertion/deletion/cut editing, queued cancellation, browser-versus-FFmpeg framing pixels at 2× zoom, rotated-source probing/render, real FFmpeg export, tenant isolation and project deletion locally; a separate FFmpeg ASS/frame test checks overlapping speakers, **but its transcription and billing adapters are explicitly offline fakes**. The native Workers AI adapter, explicit Deepgram fallback, schema and chunk-merging code also have offline contract tests. The actual Container image was built locally: it extracted three segments from a 126-second recording and **120 bounded segments from a 7,199-second recording**. **Guarded staging is deployed** at [clipforge-staging-web.odysseas-patra.workers.dev](https://clipforge-staging-web.odysseas-patra.workers.dev) with an allowlisted owner mailbox, TEST Stripe and Cloudflare Email Sending on the independently approved `staging.clipforge.odysseas.tech` subdomain. The owner account signed in; Stripe TEST Checkout completed and its signed invoice webhook granted 120 minutes exactly once. A 43-second locally synthesized English interview was customer-uploaded to R2, processed by a real Container and Cloudflare Nova-3 (99 timed words, one candidate); after a boundary/crop/caption edit, a failed render was retried with the same fenced job and produced a **real** authenticated H.264/AAC, 1080×1920, 20-second MP4. That proves a short staging path, **not** human-mailbox delivery, diarization with multiple speakers, long-media scale, renewal webhooks, actual billed model costs, or readiness for open signup. The Cloudflare email binding accepted verification/reset sends; the owner's verification and reset were exercised with securely generated/queried one-time tokens, not observed inbox delivery. Staging signup remains restricted to the owner mailbox. A separate **$3 total staging model-inference allowance** is approved; D1 now records one of ten allowed source minutes (published Nova HTTP-rate estimate ~$0.0052), but provider billing remains to be checked. No live Stripe charges or production deployment occurred.

See [staging operations and hard gates](docs/operations.md). This stack refuses to operate outside the `staging` stage and refuses non-TEST Stripe keys. Never run `alchemy dev`, `plan` or `deploy` assuming those are local: they can contact and create real resources. Production merge/deploy is not authorized.
